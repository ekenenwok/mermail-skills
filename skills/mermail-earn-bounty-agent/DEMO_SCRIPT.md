# Demo Video Script (for the required 2–5 min video)

Record your screen and narrate these beats in order — this maps directly to what the judging criteria asks for.

1. **Trigger prompt (0:00–0:20)**
   Say out loud: "I'm going to check my Mermail inbox for bounty emails."
   Type the prompt: `Check my bounty email`

2. **Skill connects to Mermail (0:20–0:50)**
   Let the agent run. Show it listing/reading the matching email(s) via the Mermail tool call — don't skip past this part, it's the "working demo" requirement.

3. **Agent completes the workflow (0:50–2:30)**
   Show it parsing the email into `BRIEF.md`, creating `SUBMISSION.md`, and updating `INDEX.md`. Narrate what each file is for as it appears.

4. **Final result (2:30–3:30)**
   Open the generated `bounties/<slug>/` folder and show the three files with real content pulled from the actual email — not placeholder text.

5. **Wrap (3:30–4:00)**
   One sentence on why this is reusable: "This works for any bounty platform that emails notifications, not just this one."
